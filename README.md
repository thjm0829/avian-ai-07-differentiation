# 7. 차별성 및 경쟁력

> **작성 상태:** 세부 내용 작성 완료
>
> **핵심 결론:** 본 사업의 경쟁력은 개별 센서나 신속항원키트, 카메라 판독기 하나에 있지 않다. 계분벨트의 설정된 Sampling Point에서 반복 복합시료를 만들고, AIV 신속항원검사의 정성·반정량 optical signal을 동일 조건에서 축적하여 자동 재검과 공식 확인검사 우선순위로 연결하며, 향후 허가된 축산차량·시설 이동관계까지 결합하는 농장형 연속 초동경보 체계에 있다.

본 사업은 기존 국가 조류인플루엔자 방역체계와 공식검사를 대체하지 않는다. 공식검사와 다음 검사 사이의 농장 내부 관찰 공백을 반복 자동검사로 보완하고, 전문기관의 확인이 필요한 농장을 더 빠르게 선별하는 예찰보조 시스템으로 경쟁력을 확보한다.

차별성은 다음 세 가지 기술축의 결합에서 형성된다.

1. **Automated Bio-Surveillance Node:** 농장에서 반복 가능한 분변 검사데이터를 자동으로 생성한다.
2. **AI Early Warning Engine:** 동일 Sampling Point의 검사이력과 재검 결과를 분석하여 위험단계, 판단 이유 및 권고 조치를 제시한다.
3. **Epidemiological Risk Graph:** 향후 기관 협력과 데이터 이용권한을 전제로 농장·차량·시설의 이동관계를 분석하여 확인 우선순위를 지원한다.

현재 핵심 제품은 첫 번째와 두 번째 기술축인 자동검사 장치와 AI 조기경보 플랫폼이다. 세 번째 기술축은 공공기관 협력, 법적 검토 및 데이터 연계조건이 갖추어진 이후 적용하는 단계적 고도화 기술로 구분한다.

## 서면평가 ‘독창성’ 대응 요약

본 사업의 독창성은 카메라, 신속항원키트 또는 AI 모델 하나를 새로 발명했다는 주장에 있지 않다. **농장 분변 채취부터 공식검사 연결까지 끊어져 있던 기능을 반복 가능하고 추적 가능한 폐쇄형 업무흐름으로 결합한 시스템 설계**에 있다.

| 비교차원 | 기존 방식에서 일반적인 단위 | 본 사업의 결합방식 | 심사 시 제시할 증거 |
|---|---|---|---|
| 시료 확보 | 사람이 특정 시점에 채취 | 계분벨트의 설정지점에서 여러 시점 소량채취 후 Composite Sample 생성 | Sampling 구조도와 State Machine |
| 검사 수행 | 수동 전처리·분주·시간관리 | 일회용 Wet Zone에서 혼합·침전·상층액·분주 자동화 | 모듈 구성도와 반복성 검증계획 |
| 판독 | 육안 양성·음성 또는 판독기 단품 | 고정광학 기반 정성·반정량 신호와 QC 동시기록 | C/T ROI, T/C와 QC 데이터 구조 |
| 시간축 | 한 번의 검사결과 | 동일 Sampling Point의 반복이력·변화추세 | 시계열 예시와 농장별 baseline |
| 오류처리 | 무효·약신호 후 수동 판단 | Invalid·Uncertain 분리, 자동재검과 Reason Code | 재검 상태머신과 조치이력 |
| 방역연결 | 검사결과와 공식절차가 분리 | 관리자 확인과 전문기관 공식검사 필요성 지원 | 역할분리표와 연결 SOP |
| 사업단위 | 키트·판독기·센서 개별 판매 | 장치+소모품+공공관제+유지관리 B2G2B | 8·9장의 계약·수익구조 |
| 후속확장 | 이동이력 또는 농장센서 개별 분석 | 권한 확보 후 생물학적 신호와 이동관계의 우선순위 결합 | 단계별 Risk Graph 계획 |

### 독창성의 핵심 조합

~~~text
반복 Composite Sampling
        +
상용 AIV 키트 자동검사
        +
정성·반정량 Optical Signal과 QC
        +
동일 지점 시계열·자동재검
        +
공식검사 연결과 공공 관제
~~~

각 요소에는 선행기술이 존재할 수 있으므로 “세계 최초”, “유일한 기술” 또는 “동일 경쟁제품 부재”를 근거 없이 사용하지 않는다. 공모전에서는 **요소기술의 신규성보다 농장 방역 문제를 해결하는 결합구조와 운영혁신**을 독창성의 중심으로 제시한다.

## 공모전 단계 경쟁분석 범위

현재 경쟁분석은 공식검사, 수동 AIV 신속항원키트, 디지털 판독기, 축사 센서·영상 AI, KAHIS와 선행특허를 기능단위로 비교한다. 이는 본 시스템이 기존 체계를 대체하지 않고 여러 기능을 연결한다는 점을 설명하기 위한 객관적 비교다.

- 공개자료로 확인하지 않은 제품가격, 국내 유통상태, 허가범위와 실제 설치실적은 확정 비교표에 넣지 않는다.
- “동일 경쟁제품이 없다”거나 “세계 최초”라고 표현하지 않는다.
- 공모전 제출 전에는 위 실명 비교대안의 공식자료와 선행특허를 검토하고, 시제품 사양이 고정된 뒤 견적·국내 공급조건·허가상태·특허 청구항을 기준으로 제품단위 Benchmark와 FTO 검토를 갱신한다.
- 경쟁제품보다 우수하다는 결론은 Sampling–전처리–판독–시계열–재검–공식연결의 End-to-End 성능을 실증한 뒤 확정한다.

## 7.1 기존 방식 비교

### 1. 경쟁·대체 방식 비교

| 비교 대상 | 기존 방식의 주요 역할과 강점 | 기존 방식만으로 남는 운영 공백 | 본 시스템의 차별화 방향 | 대체 여부 |
|---|---|---|---|---|
| 공식 예찰·RT-qPCR 등 전문검사 | 확진과 법정 방역조치의 기준, 높은 분석 성능, 아형 확인 | 모든 농장을 매우 짧은 간격으로 반복 검사하기에는 인력·시설·비용 부담이 큼 | 공식검사 사이의 농장 내부 감시를 보완하고 확인검사 우선순위를 제공 | 대체하지 않음 |
| 수동 AIV 신속항원키트 | 현장에서 짧은 시간 안에 1차 선별 가능 | 수동 채취·전처리·판독에 의존하고 단발성 정성결과로 끝나는 경우가 많음 | 채취부터 판독·기록·재검까지 자동화하고 동일 지점의 반복검사 이력을 생성 | 운영방식을 확장 |
| 일반 디지털 신속검사 판독기 | C선과 T선을 촬영하고 신호강도를 수치화 | 판독 전의 시료채취·전처리와 판독 후의 농장별 시계열·재검 흐름이 분리됨 | 농장 분변 채취부터 위험경보와 공식검사 연결까지 하나의 폐쇄형 흐름으로 구성 | 판독기 단품과 구분 |
| 축사 환경센서·영상 AI | 온도·습도·활동량·음향·폐사·분변 외관 등 비접촉 감시 | 이상징후는 감지할 수 있지만 AIV 항원을 직접 확인하는 신호는 아님 | 분변 기반 AIV 항원검사를 핵심 직접신호로 두고 환경·생산데이터는 보조문맥으로 사용 | 상호보완 |
| KAHIS·축산차량 GPS·공식 역학조사 | 농장·시설·차량정보와 방문이력을 활용한 국가 방역 및 역학조사 | 농장에서 새로 생성되는 반복 생물학적 검사신호와의 결합은 별도 협력과 권한이 필요 | 향후 허가된 이동관계에 농장 자체 위험신호를 결합해 관련 농장 확인 우선순위를 제안 | 공식체계를 지원 |

### 2. 공식검사와의 관계

세계동물보건기구 WOAH의 조류인플루엔자 진단기준에 따르면 면역크로마토그래피 방식의 현장 항원검사는 비교적 짧은 시간에 Influenza A 항원을 선별할 수 있지만, 민감도와 검체·축종별 성능 차이, 아형 확인 한계가 있어 보다 민감한 실험실 검사와 연계하여 해석해야 한다.

따라서 본 시스템은 다음 역할을 담당한다.

- 반복검사에서 발생한 이상신호의 조기 포착
- 품질정보를 포함한 자동 재검
- 공식 확인검사가 필요한 농장의 우선순위 제시
- 농장 관리자와 방역담당자에게 판단 이유 및 권고 조치 제공
- 공식검사 요청 시 과거 검사이력과 장치상태를 함께 제공

본 시스템의 결과만으로 AIV 감염을 확진하거나 이동제한·살처분 등 법정 방역조치를 결정하지 않는다.

### 3. 수동 신속항원검사와의 차이

수동 신속항원검사는 주로 한 시점의 검체를 사람이 전처리하고 육안으로 양성·음성·무효를 판독한다. 반면 본 시스템은 다음 과정을 하나의 데이터 생성 흐름으로 연결한다.

~~~text
계분벨트의 설정된 Sampling Point
        ↓
여러 시점 반복 소량채취
        ↓
Composite Sample 생성
        ↓
일회용 전처리부에서 혼합·침전
        ↓
상층액 자동분주
        ↓
상용 AIV 신속항원키트 검사
        ↓
고정 카메라·조명 기반 C선·T선 판독
        ↓
정성결과 + T/C 반정량 optical signal + QC 기록
        ↓
동일 Sampling Point 시계열 분석
        ↓
자동 재검·관리자 확인·공식검사 연결
~~~

차별성은 신속항원키트 자체의 성능을 변경하는 데 있지 않다. 검사가 수행되는 조건과 이력을 표준화하고, 기존에는 소실되기 쉬웠던 반복검사 신호를 장기 데이터로 전환하는 데 있다.

### 4. 디지털 판독기 및 축사 영상기술과의 차이

신속검사 카세트의 C선·T선 촬영과 신호강도 수치화 기술은 이미 다양한 분야에서 연구·제품화되어 있다. 또한 계분벨트 위에서 카메라로 분변의 색상·형태·수분상태를 분석하는 선행기술도 존재한다.

따라서 다음 요소를 단독 경쟁우위로 주장하지 않는다.

- 카메라로 신속키트를 촬영하는 기능
- T선과 C선의 픽셀강도를 계산하는 기능
- 계분벨트 위에 카메라를 설치하는 구조
- 분변 외관을 AI로 분류하는 기능
- 상용 신속항원키트를 사용하는 것 자체

본 시스템의 차이는 분변의 외관만 보는 것이 아니라, 설정된 지점에서 생성한 통합시료를 전처리하여 AIV 항원검사를 수행하고 그 결과를 반복 시계열과 재검 절차로 연결한다는 점이다.

### 5. 기존 이동이력 시스템과의 차이

국내에는 이미 국가가축방역통합시스템 KAHIS와 축산차량 GPS 등록체계가 존재한다. 차량의 축산관계시설 방문정보는 공식 방역과 역학조사에 활용되며 관련 정보의 수집·이용에는 법적 근거와 접근통제가 적용된다.

따라서 Epidemiological Risk Graph의 차별성은 차량을 새로 추적한다는 데 있지 않다. 기관 협력과 정당한 이용권한을 전제로 다음 정보를 결합하는 데 있다.

- 농장별 반복검사 Risk Score와 Risk Level
- 이상신호 발생시점과 자동 재검 결과
- 농장·차량·시설의 시간순 방문관계
- 주변 발생정보와 방역조치 상태
- 관련 농장과 확인 대상의 우선순위

이 기능은 공식 역학조사를 자동으로 대체하거나 감염경로를 확정하지 않는다. 제한된 인력으로 먼저 확인해야 할 연결관계를 제안하는 의사결정 지원기능으로 정의한다.

## 7.2 반복검사와 반정량 추세분석의 의미

### 1. 반복검사의 목적

신속항원검사는 검체의 바이러스량, 채취시점, 검체상태, 축종과 키트 성능에 따라 결과가 달라질 수 있다. 한 번의 음성 결과를 농장 전체의 안전 판정으로 해석해서는 안 되며, 반복검사를 수행한다고 해서 키트 자체의 분석민감도가 자동으로 높아지는 것도 아니다.

본 시스템에서 반복검사의 의미는 다음과 같다.

- 한 시점의 결과가 아니라 시간에 따른 변화방향을 관찰
- 동일 Sampling Point와 유사한 운전조건에서 결과를 비교
- 일시적인 채취·분주·판독 오류와 반복되는 이상신호를 구분
- 농장별 정상 기준선과 계절·운영조건에 따른 변동을 축적
- 자동 재검을 통해 공식검사 연결 전 품질확인 절차를 수행
- 검사누락, 무효, 장치이상까지 포함한 전체 검사이력을 보존

반복검사의 사업적 가치는 단발성 검사횟수를 늘리는 것보다, 검사조건과 결과를 추적 가능한 데이터로 만들고 이상신호 발생 후의 다음 조치를 표준화하는 데 있다.

### 2. 반정량 optical signal의 의미

카메라는 고정된 조명과 촬영조건에서 신속항원키트의 C선과 T선을 촬영한다. 시스템은 정성결과와 함께 신호강도 및 품질정보를 기록한다.

| 데이터 | 활용 의미 | 해석상 제한 |
|---|---|---|
| C선 신호 | 키트 전개 여부와 판독 유효성 확인 | 시료품질 전체를 보증하지 않음 |
| T선 신호 | 항원반응의 광학적 신호 기록 | 바이러스 절대농도가 아님 |
| T/C 반정량 신호 | 촬영조건과 일부 공통변동을 보정한 상대지표 | RNA copy 수 또는 감염력으로 직접 환산하지 않음 |
| 직전 대비 변화량 | 동일 지점의 단기 변화 확인 | 단일 변화만으로 감염을 판정하지 않음 |
| 최근 N회 추세 | 연속 상승·반복 이상 여부 확인 | 기준횟수와 임계값은 실증으로 결정 |
| QC 정보 | 흐림, 과노출, 카세트 위치, C선 이상 등 판독품질 관리 | 진단성능과 별도로 평가 |

T/C 신호와 실제 바이러스량 또는 RT-qPCR 결과의 상관관계는 전문기관 실증을 통해 별도로 확인한다. 검증 전에는 바이러스량, RNA copy 수 또는 정량 진단값으로 표현하지 않는다.

### 3. 비교 가능한 시계열을 위한 조건

서로 다른 시점의 값을 비교하려면 다음 조건을 함께 관리해야 한다.

- Sampling Point와 Sampling Cycle 식별자
- 벨트 운전상태와 Sampling Event 기록
- 통합시료 생성과 전처리 조건
- 완충액·시료량·혼합·침전시간
- 상층액 흡입높이와 분주량
- 키트 제조사·모델·로트·유효기간
- 검사 시작시각과 판독시각
- 카메라 노출·초점·조명·ROI
- 카트리지와 키트 장착상태
- 환경·생산 보조데이터와 세척이력
- 장치 점검·고장·소모품 교체이력

키트 또는 로트가 변경되면 동일한 수치기준을 그대로 적용하지 않는다. Kit Profile과 Lot Profile을 구분하고, 필요하면 중첩 비교기간과 재기준화 절차를 적용한다.

### 4. 자동 재검과 설명 가능한 경보

이상신호 발생 시 운영 흐름은 다음과 같다.

~~~text
이상신호 탐지
    ↓
C선·영상·장치상태·시료처리 QC 확인
    ↓
동일 조건 자동 재검
    ↓
정상 복귀 → 일시 이상으로 기록하고 모니터링 유지
반복 이상 → 관리자 확인 및 공식검사 권고
    ↓
Risk Score + Risk Level + Reason Codes + Recommended Action 제공
~~~

Reason Codes에는 예를 들어 연속 T/C 상승, 반복 양성, 농장 기준선 이탈, 자동 재검 이상, C선 불량, 영상품질 저하, 장치동작 이상 등을 포함할 수 있다. 실제 임계값과 재검횟수는 6장의 단계적 실증결과를 통해 결정한다.

## 7.3 핵심 차별점

### 차별점 1. 시료채취부터 경보까지 연결된 폐쇄형 자동화

일반적인 현장 신속검사는 채취, 전처리, 판독, 기록과 후속조치가 사람의 작업과 개별 문서에 나뉘기 쉽다. 본 시스템은 이 과정을 장치와 플랫폼의 하나의 검사 Cycle로 연결한다.

- Sampling Event 자동기록
- Composite Sample 생성
- 일회용 전처리와 상층액 분주
- 신속항원키트 자동검사
- 카메라 판독과 QC
- 검사이력 저장
- 이상신호 분석
- 자동 재검 및 공식검사 권고

이 구조는 검사결과뿐 아니라 결과가 만들어진 과정의 추적성을 함께 제공한다.

### 차별점 2. 고정 지점 반복 소량채취와 Composite Sample

한 덩어리의 분변을 일회성으로 검사하는 대신, 벨트 운전 중 여러 시점에 소량을 채취하여 해당 Sampling Point의 통합시료를 만든다. 이는 특정 개체나 한 순간의 시료에 과도하게 의존하는 문제를 줄이기 위한 설계가설이다.

다만 현재 1 Sampling Point가 축사 전체를 완전히 대표한다고 가정하지 않는다. 반복채취의 재현성과 대표성은 농장 실증에서 검증하며, 필요하면 향후 2~3개의 독립 노드를 사용하는 Multi-point Monitoring으로 확장한다.

### 차별점 3. 정성검사의 데이터 자산화

육안 양성·음성으로 끝나는 결과를 다음과 같은 구조화 데이터로 전환한다.

- 원본 검사이미지
- 양성·음성·무효 정성결과
- C선과 T선 신호
- T/C 반정량 optical signal
- 판독시각과 키트·로트정보
- QC 결과
- 동일 지점 과거 이력
- 자동 재검 결과
- 판단 이유와 권고 조치
- 공식검사 결과가 확보된 경우 비교 Label

장기적으로 경쟁력은 개별 알고리즘보다 농장 현장에서 일정한 조건으로 축적되고 공식 기준검사와 연결된 시계열 데이터에서 형성된다.

### 차별점 4. 설명 가능한 AI 조기경보

초기 시스템은 데이터가 부족한 상태에서 복잡한 AI 모델을 먼저 적용하지 않는다. 규칙기반·통계기반 분석으로 시작하여 어떤 신호가 경보에 영향을 주었는지 설명한다.

- 현재 검사결과
- 농장별 기준선 대비 편차
- 직전 검사 대비 변화량
- 최근 N회 변화 추세
- 자동 재검의 일치 여부
- 검사품질과 장치상태
- 환경·생산 보조데이터

공식검사 Label과 장기운영 데이터가 축적된 이후에만 머신러닝 적용범위를 확대한다. 모델이 변경되더라도 판단근거, 버전, 입력데이터와 결과를 추적할 수 있도록 한다.

### 차별점 5. 농장 운영환경을 고려한 Wet Zone과 Dry Zone 분리

분변 원시료와 상층액에 접촉하는 부분은 가능한 한 일회용 Wet Zone 안에 제한한다. 모터, 카메라, 제어기, 통신부 등은 재사용하는 Dry Zone으로 분리한다.

이 구조가 목표로 하는 운영상 이점은 다음과 같다.

- 검체 교차오염 위험 감소
- 세척이 어려운 농장 환경에서의 작업 단순화
- 작업자의 직접 검체접촉 감소
- 카트리지 단위의 추적성 확보
- 유지보수 범위와 폐기물 범위의 분리

실제 오염감소율과 유지관리 효과는 6장의 Mock Test, 전문기관 비교 및 농장 실증으로 확인한다.

### 차별점 6. 생물학적 위험신호와 이동관계의 단계적 결합

현재 제품은 Automated Bio-Surveillance Node와 AI Early Warning Engine을 우선 구현한다. 이후 공공기관 및 데이터 보유기관과의 협력이 가능해지면 Epidemiological Risk Graph를 추가한다.

이때 경쟁력은 단순한 이동경로 조회가 아니라 다음 세 위험축의 결합에서 형성된다.

- **Bio Risk:** 반복 AIV 검사와 재검에서 나타난 생물학적 이상신호
- **Context Risk:** 환경·생산·주변 발생정보 등 농장 문맥
- **Movement/Network Risk:** 허가된 농장·차량·시설 이동관계

세 위험축을 결합하여 공식 확인이 필요한 농장과 연결관계의 우선순위를 제안하되, 감염경로나 법정 방역조치를 자동 확정하지 않는다.

## 7.4 기술적 진입장벽

### 1. 현장 Sampling 및 전처리 노하우

모터·카메라·펌프와 상용 키트는 조달할 수 있지만, 실제 계분벨트 환경에서 반복 가능한 시료를 만드는 것은 별도의 현장기술이 필요하다.

- 농장별 벨트 구조와 계분 낙하특성 파악
- Sampling Point 선정과 설치공차
- 벨트 운전을 방해하지 않는 진입·복귀 동작
- 여러 Sampling Event의 균일한 통합
- 분변 점도·수분·협잡물 변화에 대응하는 전처리
- 고형물을 피한 상층액 채취
- 검체접촉부와 재사용부의 오염분리
- 분진·습기·부식·세척환경에 대한 내구성

이러한 설치·운영·유지보수 데이터는 농장 실증이 누적될수록 후발주자가 단기간에 복제하기 어려운 현장자산이 된다.

### 2. 검증된 검사 프로토콜과 데이터셋

실제 진입장벽은 단순한 AI 모델보다 다음 데이터의 결합에서 형성된다.

- Sampling Point별 반복검사 이력
- 원본영상과 C선·T선 신호
- 전처리·분주·판독 QC
- 키트·로트·장치 버전
- 환경·생산 보조데이터
- 자동 재검 결과
- 전문기관 RT-qPCR 등 기준검사 결과
- 경보 이후 실제 조치와 결과

특히 음성·양성뿐 아니라 무효검사, 장치오류, 일시적 이상, 재검 불일치와 같은 실패데이터를 축적해야 실제 농장 운영에 강한 시스템을 만들 수 있다.

### 3. 장치·소모품·플랫폼 통합운영

진입장벽은 하드웨어 도면 하나가 아니라 다음 요소가 함께 작동하는 운영체계에서 발생한다.

- 장치 펌웨어와 검사 Cycle 제어
- Composite Cartridge와 Kit Adapter
- Kit Profile·Lot Profile 관리
- 카메라 보정과 영상판독 알고리즘
- 엣지 저장·오프라인 동작·서버 동기화
- 원격진단과 예방정비
- 소모품 공급과 폐기절차
- 검사·장치·사용자 감사로그
- 보안·권한·데이터 보존정책

### 4. 기관협력과 데이터 거버넌스

Movement Risk Layer는 기술만으로 구현할 수 없다. 이동이력과 공식검사 데이터에는 법적·제도적 접근조건이 있으므로 다음 요소가 진입장벽이자 필수조건이 된다.

- 지자체·방역기관·수의전문기관과의 실증협력
- 데이터 이용목적과 최소수집 원칙
- 농장·차량·시설 식별정보의 접근통제
- 공식검사 결과의 안전한 연계
- 데이터 보존기간과 파기정책
- 모델결과의 책임범위와 사람의 최종판단
- 국가방역체계와의 상호운용성

기관협력이 확보되지 않은 단계에서는 공개정보, 모의 이동데이터 또는 농장이 직접 제공한 데이터만으로 기능을 검증한다.

### 5. 지식재산권 전략

선행기술에는 계분벨트 위 카메라를 이용한 분변 외관 감시, 신속검사 카세트의 광학 판독, 자동 시료준비와 판독장치 등이 존재한다. 따라서 카메라, 컨베이어 또는 신속키트 사용 자체를 넓게 독점하려는 접근은 방어력이 낮을 수 있다.

우선 검토할 지식재산권 범위는 다음과 같다.

- 계분벨트 낙하구간에서의 반복 소량채취와 Composite Sample 생성구조
- 일회용 카트리지 내부 혼합·침전·상층액 채취구조
- Sampling Cycle과 키트 검사 Cycle의 연동방법
- QC를 포함한 자동 재검 조건과 운영방법
- 동일 Sampling Point 반정량 시계열에 기반한 경보방법
- 장치검사 위험도와 허가된 이동관계의 결합방법
- Wet Zone과 Dry Zone의 오염방지 인터페이스

이는 초기 선행기술 검토방향이며, 출원 전 국내외 특허전문가를 통한 정식 선행기술조사와 청구항 검토가 필요하다.

### 6. 진입장벽으로 과대평가하지 않을 요소

다음 항목은 경쟁에 필요한 구성요소이지만 그 자체만으로 강한 진입장벽이 되기는 어렵다.

- 상용 AIV 신속항원키트 구매
- 범용 카메라·모터·펌프 사용
- 일반적인 대시보드와 알림기능
- 검증되지 않은 AI 모델 또는 Risk Score
- 단순한 농장·차량 네트워크 시각화
- 정확도 검증이 없는 T/C 수치화

따라서 장기 경쟁우위는 특허, 현장운영 노하우, 기준검사와 연결된 데이터, 공급·정비체계 및 기관협력을 함께 축적하는 방식으로 구축한다.

## 7.5 지속가능성

### 1. 기술적 지속가능성

특정 키트나 단일 하드웨어에 종속되지 않도록 모듈형 구조를 유지한다.

- 키트별 교체 가능한 Kit Adapter
- 판독시간·ROI·C선·T선 위치를 정의하는 Kit Profile
- 로트 변경 시 보정 가능한 Lot Profile
- Sampling Unit과 Analysis Unit의 독립 교체
- 엣지 기반 기본검사와 통신복구 후 서버 동기화
- 장치·펌웨어·알고리즘 버전관리
- 소모품 교체와 예방정비 주기관리
- 향후 Multi-point Node 추가가 가능한 확장구조

키트 변경 시에는 제조사의 허용검체, 전처리방법, 판독시간과 규제·검증상태를 다시 확인한다. 서로 다른 키트의 반정량 신호를 동일한 기준으로 직접 비교하지 않는다.

### 2. 데이터와 AI의 지속가능성

데이터가 증가할수록 모델을 복잡하게 만드는 것이 아니라, 데이터 품질과 추적성을 먼저 유지한다.

- 원본데이터와 가공데이터 분리보관
- 검사·재검·공식검사 Label 연결
- 농장·Sampling Point별 기준선 관리
- 데이터 누락과 센서오류 모니터링
- 모델 버전별 성능과 경보기준 기록
- 계절·농장유형·키트변경에 따른 데이터 드리프트 확인
- 오경보와 미탐사례의 사후분석
- 설명 가능한 Reason Codes 유지

머신러닝은 충분한 Label과 외부검증이 확보된 이후 적용하며, 기존 규칙기반 기준과 비교하여 실제 개선이 확인된 경우에만 운영범위를 확대한다.

### 3. 사업운영의 지속가능성

사업모델은 초기 실증결과와 구매주체의 요구에 따라 다음 요소를 조합할 수 있다.

- 장치 판매 또는 임대
- Composite Cartridge와 검사키트 등 소모품 공급
- 정기점검·원격진단·유지보수
- AI Early Warning Platform 사용료
- 지자체·협회·계열화사업자 단위 통합관제
- 전문기관 실증·데이터 분석 서비스

소모품 반복매출이나 플랫폼 구독을 사전에 확정된 수익으로 표현하지 않는다. 농장과 공공부문의 지불의사, 검사주기, 유효검사 1회당 비용 및 유지관리 부담을 실증한 뒤 가격과 공급방식을 결정한다.

### 4. 제도적·사회적 지속가능성

가축방역 분야에서는 기술성능뿐 아니라 기존 제도와의 역할분담이 장기운영에 중요하다.

- 공식검사와 법정 방역조치의 권한을 침해하지 않음
- 농장데이터와 이동정보의 최소수집·목적제한
- 사용자 역할별 접근권한과 감사로그
- 위험경보의 판단근거와 책임범위 명시
- 농장에 불이익을 줄 수 있는 오경보 대응절차
- 방역기관·수의전문가가 검토할 수 있는 데이터 형식
- 개인정보·영업정보·방역정보에 대한 보안정책
- 사람의 최종판단을 유지하는 Human-in-the-loop 운영

### 5. 지속가능성 평가 KPI

| 평가영역 | 주요 KPI | 확인 목적 |
|---|---|---|
| 장치운영 | 가동률, Sampling 성공률, 전처리·분주 성공률 | 실제 농장 장기운영 가능성 |
| 검사품질 | 유효검사율, 무효율, 재검 일치율, QC 실패율 | 반복검사의 신뢰성과 표준화 |
| 경보성능 | 공식검사 대비 민감도·특이도, 오경보율, 미탐률 | 예찰보조 성능 검증 |
| 대응효율 | 이상신호부터 재검·관리자 확인·공식검사 요청까지의 시간 | 조기선별의 운영효과 |
| 경제성 | 유효검사 1회당 비용, 농장당 월 운영비, 유지관리시간 | 구매·운영 지속가능성 |
| 데이터품질 | 누락률, Label 확보율, 장치·키트 메타데이터 완전성 | AI 고도화 가능성 |
| 서비스운영 | 장애복구시간, 소모품 공급준수율, 원격해결률 | 확장 가능한 서비스체계 |
| 기관연계 | 실증기관 수, 공식검사 연계건수, 데이터협약 범위 | 제도권 적용 가능성 |

목표수치는 6장의 단계별 검증과 실제 농장 실증에서 기준값을 확보한 후 설정한다. 검증되지 않은 정확도, 탐지시간 단축률, 비용절감률 또는 피해예방액을 사전에 확정하여 제시하지 않는다.

## 7장 종합 경쟁우위

본 사업의 경쟁우위는 다음과 같이 정리한다.

> **기존 국가 방역체계를 대체하지 않으면서, 농장 계분벨트에서 반복 가능한 AIV 검사데이터를 자동 생성하고, 정성·반정량 신호와 품질정보를 동일 지점의 시계열로 분석하여 자동 재검과 공식 확인검사 우선순위로 연결하며, 향후 허가된 이동관계까지 결합할 수 있는 통합형 농장 초동경보 플랫폼**

경쟁우위의 형성순서는 다음과 같다.

1. 반복 가능한 Sampling 및 Analysis Unit 확보
2. 농장 장기운영과 기준검사 비교를 통한 검사 프로토콜 검증
3. 동일 Sampling Point 시계열·재검·실패데이터 축적
4. 설명 가능한 AI Early Warning Engine 고도화
5. 소모품·정비·플랫폼 통합운영체계 구축
6. 기관협력과 권한을 바탕으로 Epidemiological Risk Graph 확장

이 순서를 통해 개별 부품을 쉽게 모방할 수 있더라도, 검증된 프로토콜과 데이터, 운영체계 및 기관협력의 결합은 단기간에 복제하기 어려운 경쟁기반으로 발전시킨다.
